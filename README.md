# Human Resource Management System (HRMS)

A full-stack Human Resource Management System built using ASP.NET Core Web API and Angular.

---

## Tech Stack

### Backend
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- JWT Authentication

### Frontend
- Angular 19
- TypeScript
- SCSS

---

## Project Structure

```text
HRMS/
│
├── HRMS.API/
├── hrms-client/
├── Documentation/
└── README.md
```

---

## Setup Instructions

### Backend

```bash
cd HRMS.API
dotnet run
```

### Frontend

```bash
cd hrms-client
ng serve
```
